# Ranz Global

Kurumsal vize sitesi, müşteri/danışman portalı ve yapay zeka SEO paneli.

## Çalıştırma

```bash
npm install
npm run dev
```

[http://localhost:3000](http://localhost:3000)

## Demo hesaplar

| Rol | E-posta | Şifre |
| --- | --- | --- |
| Müşteri | `ayse@ranz.demo` | `ranz2026` |
| Danışman | `danisman@ranz.demo` | `ranz2026` |
| Yönetici | `yonetici@ranz.demo` | `ranz2026` |

Yönetici: `/yonetim` (istatistik, CMS) ve `/yonetim/seo`.

Veriler tarayıcıda (localStorage) durur. GSC/GA4 OAuth, SERP API ve gerçek dosya deposu sonraki entegrasyon fazındadır.

## Teklif kapsamı (bu depo)

- Paket A: kurumsal site (TR/EN), CMS, müşteri girişi, evrak, danışman kuyruğu, istatistik
- Paket B: SEO spider, onaylı onarım, içerik kuyruğu, kelime, rakip, GSC/GA4 yerleri, bot, uptime, etkileşim, backlink
